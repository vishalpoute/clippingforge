## Team Roles & Ownership

| Agent | Role | Primary Ownership |
|-------|------|-------------------|
| **Agent 1** | Project Lead / Software Architect | Overall architecture, milestone planning, coordination |
| **Agent 2** | Frontend Engineer | Next.js 14 UI, design system, video editor, metadata controls |
| **Agent 3** | Backend Engineer | FastAPI APIs, database models, durable job queue |
| **Agent 4** | AI/ML Engineer | OmniRouter integration, transcription, viral scoring |
| **Agent 5** | Video Processing Engineer | FFmpeg pipelines, clipping, cropping, subtitle rendering |
| **Agent 6** | Social Platform Integration Engineer | YouTube, Instagram, Facebook OAuth & publishing |
| **Agent 7** | DevOps Engineer | Native Windows PowerShell scripts, local performance |
| **Agent 8** | QA & Security Engineer | Test suites, regression verification, security audits |

Refer to [docs/03-agents/AGENTS.md](docs/03-agents/AGENTS.md) for complete collaboration guidelines, coding conventions, and review procedures.
