# PROJECT.md

## Vision
Create an AI‑powered SaaS that turns long‑form videos and livestreams into short, platform‑optimized clips with automated publishing.

## Core Features
- Video upload / import (YouTube, Kick, direct file)
- Automatic transcription (Faster‑Whisper)
- AI‑driven viral moment detection (OmniRouter)
- Clip generation with smart cropping & animated captions
- Complete professional video editor with timeline scrubbing
- Complete metadata editor (titles, descriptions, hashtags, thumbnails)
- Scheduling & publishing to YouTube Shorts, Instagram Reels, Facebook Reels
- Dashboard for monitoring, editing, analytics

## Non‑Goals
- Desktop raw timeline compositor replacement (like Premiere/DaVinci)
- Real‑time streaming overlays
- Support for TikTok (out of scope for initial MVP)

## Success Criteria
- End‑to‑end workflow works on a real video file.
- All health checks pass.
- Unit tests > 80% coverage for core modules.
- Smooth native performance on Windows 11.
