## Multi-worker and creator monitoring checkpoint (2026-11-23)

Import enqueue is serialized on SQLite. Active or completed canonical jobs are reused; explicit retries reset the retry state, while scheduled monitor polls do not retry terminal jobs. Stale recovery is an atomic update, and the worker sweeps periodically between jobs. Imports renew their lease even when no download progress arrives. Cancelling an owned import retains its slot until the handler exits or the lease expires, so a second worker cannot immediately reuse the same partial files.
