# AI_PIPELINE.md

## Overview (Milestone 1)

The AI pipeline is *planned* for later milestones. At this stage we only define the **interface** that other services will call.

### Intended responsibilities
- Receive a video ID.
- Pull the transcript (generated by the transcription service).
- Call the local OmniRouter model to:
  * Rank candidate moments.
  * Generate titles, descriptions, hashtags.
- Return a JSON payload containing:
  ```json
  {
    "candidates": [{
      "start_ms": 12345,
      "end_ms": 23456,
      "viral_score": 84.2,
      "explanation": "..."
    }],
    "metadata": {
      "title": "...",
      "description": "...",
      "hashtags": ["#example"]
    }
  }
  ```

### Current status
- **Stub endpoint** will be added in `services/api/app/services/ai/` in Milestone 3.
- No actual AI calls are performed now.

### Open questions (to be resolved later)
- Which OmniRouter model version will be used?
- How will we cache transcript results?
- Rate‑limit strategy for AI requests.
